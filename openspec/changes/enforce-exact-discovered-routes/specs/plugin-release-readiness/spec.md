### Requirement: Installed guidance cannot outrank native route discovery
Release acceptance SHALL prove that the canonical installed Skills, every retained current-identity Skill shell, and MCP descriptions contain no mutable Pi, OpenCode, or Claude model/effort inventory and no authority claim stronger than the current Driver evidence. The check SHALL mutate fake native catalogs without editing guidance and require listing plus exact spawn admission to follow only the fake native facts.

#### Scenario: Retained Skill names an obsolete route
- **WHEN** any installed or retained current-identity Skill names a model or effort as a current roster entry that fresh discovery does not own
- **THEN** release acceptance fails before installation or model usage

#### Scenario: Fake catalog changes without guidance changes
- **WHEN** the deterministic fixture replaces one model's complete effort set
- **THEN** listing and admission change accordingly while guidance remains unchanged and no paid Harness turn starts
